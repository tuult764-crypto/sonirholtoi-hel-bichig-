энэ нь миний бүтээлийг зарах сайт бөгөөд гүүглшийттэй шууд холбогддог 

## Ээлжит хичээлийн төлөвлөлт (📝 Ээлжит хичээл)
Сурах бичгийн зураг/эхээс AI ээлжит хичээлийн төлөвлөлт боловсруулж, `lesson-template.docx` загвараар Word болгон татна.
- `lesson-plan.js` — хуудасны интерфэйс (зураг оруулах, алхам засах/нэмэх/зөөх)
- `lesson-core.js` — өгөгдлийн загвар, минут тэгшлэх (сервер, хөтөч хоёуланд)
- `lesson-docx.js` — Word загварыг бөглөнө
- `server.js` дахь `POST /api/lesson-plan` — OpenAI руу дуудна. Render дээр `OPENAI_API_KEY` шаардлагатай; `LESSON_MODEL`, `LESSON_DAILY_CAP` заавал биш.
