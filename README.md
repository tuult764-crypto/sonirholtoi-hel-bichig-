# Дүрүүдийн зураг

Жинхэнэ дүрийн тус тусын зургийг энд байрлуулна. Нэр, төрхийг сольж шинэ дүр зохиохгүй.

- `tsovoo.png` — Цовоо
- `todoo.png` — Тодоо
- `enkhrii.png` — Энхрий
- `azaa.png` — Азаа
- `anir.png` — Анир

Сонголтоор чихмэл зарааны зургийг `tsovoo-plush.png` гэх мэтээр нэмж болно. Одоогоор эдгээр тус тусын зураг төслийн архивт байхгүй тул автоматаар зураг үүсгэхгүй.

## Админ удирдлага ба Анирын тэмдэглэл

- Админ: `/admin` — `ADMIN_KEY` орчны хувьсагчаар хамгаалагдана (12+ тэмдэгт).
- Анирын тэмдэглэл: `/diary.html` — зөвхөн `published` төлөвтэй бичвэрүүдийг уншигчдад харуулна.
- Админ хэсэгт тэмдэглэл болон шинэ мэдлэг, сургалтын материал, тоглоом, цахим номын сангийн агуулгыг ноорог/нийтэлсэн/архив төлөвөөр хадгалах боломжтой.
- Эдгээр агуулга `site_entries` PostgreSQL хүснэгтэд хадгалагдана. Сервер эхлэхэд хүснэгтийг автоматаар үүсгэнэ.
- Render дээр Environment хэсэгт `DATABASE_URL`, `JWT_SECRET`, `ADMIN_KEY` тохируулсан байх шаардлагатай. `ADMIN_KEY`-г кодод бичихгүй.
