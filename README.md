# Дүрүүдийн зураг

Нүүр хуудасны дүрүүдийн жинхэнэ зургаа энэ хавтсанд **яг эдгээр нэрээр** хийнэ (PNG, дэвсгэргүй нь хамгийн сайн).
Файл байхгүй үед нэрийн эхний үсэгтэй түр дугуй дүрс харагдана, файл орсон даруйд автоматаар солигдоно.

| Дүр | Зураг | Зараа чихмэл тоглоом (заавал биш) |
|---|---|---|
| Цовоо | `tsovoo.png` | `tsovoo-plush.png` |
| Тодоо | `todoo.png` | `todoo-plush.png` |
| Энхрий | `enkhrii.png` | `enkhrii-plush.png` |
| Ажаа | `ajaa.png` | `ajaa-plush.png` |
| Анир | `anir.png` | `anir-plush.png` |

- Зүүн талд том харагдах дүр нь жагсаалтын эхнийх (Цовоо). Дарааллыг `home.js` дээрх `CHARACTERS` жагсаалтаар солино.
- Чихмэл тоглоомын зураг байвал дүрийн баруун доод буланд жижиг дугуй болж харагдана.
- Нүүр хуудасны арын дэвсгэр зураг хүсвэл `images/hero-bg.jpg` нэрээр хийнэ (заавал биш).
