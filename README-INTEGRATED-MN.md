# Сонирхолтой хэл бичиг — нэгдсэн хувилбар

Энэ хувилбар нь үндсэн сайтыг хадгалж, Багшийн туслахын ажлын хуудас бэлтгэх үйлдлийг нэг домэйнд нэмнэ.

## Сайтын хаягууд
- Үндсэн сайт: `/`
- Багш нарт зориулсан хэсэг: үндсэн цэс → **Багш нарт**
- Ажлын хуудас бэлтгэх: `/bagsh/`
- Ажлын хуудасны төлбөрийн админ: `/bagsh-admin`
- Үндсэн сайтын админ: `/admin`

## Өгөгдлийн сангийн тусгаарлалт
Хоёр Supabase төслийг нийлүүлж/хуулж нэгтгээгүй. Тус тусад нь хэвээр ашиглана.
- Үндсэн сайт: `DATABASE_URL`, `JWT_SECRET`, `ADMIN_KEY`
- Ажлын хуудас: `BAGSH_DATABASE_URL`, `BAGSH_JWT_SECRET`, `BAGSH_ADMIN_KEY`

Энэ нь үндсэн сайтын худалдаа, материалын эрх, төлбөрийн хүснэгтүүд болон ажлын хуудасны хэрэглэгч/кредит/төлбөрийн хүснэгтүүдийг хооронд нь хутгахгүй.

## Render тохиргоо
Үндсэн сайтын Web Service → Environment → Secret Files хэсэгт дараах secret file-уудыг нэмнэ:

| Файлын нэр | Утга |
|---|---|
| `BAGSH_DATABASE_URL` | Багшийн туслахын Supabase Session Pooler PostgreSQL URL |
| `BAGSH_JWT_SECRET` | Хуучин Багшийн туслах Render service-ийн `JWT_SECRET` утга |
| `BAGSH_ADMIN_KEY` | Хуучин Багшийн туслах Render service-ийн `ADMIN_KEY` утга |
| `BAGSH_GEMINI_API_KEY` | Багшийн туслахад ашиглаж байсан Gemini API түлхүүр |

Environment Variables хэсэгт:
- `BAGSH_AI_PROVIDER=gemini`
- `BAGSH_QPAY_MODE=manual` (одоогийн гар төлбөрийн горим хэвээр бол)
- `BAGSH_SHEET_PRICE=500` (үнэ 500₮ хэвээр бол; өөр үнэтэй бол зөв утгаар солино)
- `BAGSH_DAILY_LIMIT=30`

**Чухал:** Үндсэн сайтын `DATABASE_URL`, `JWT_SECRET`, `ADMIN_KEY`, `OPENAI_API_KEY`-г өөрчлөхгүй. Gemini түлхүүр болон ажлын хуудасны Supabase URL-ийг үндсэн сайтынхтай андуурч сольж болохгүй.

## Deploy хийхийн өмнөх хамгаалалт
1. Одоогийн GitHub repository-г ZIP эсвэл тусдаа branch болгон backup хийнэ.
2. Энэ ZIP-ийг тусдаа тест branch/Render тест үйлчилгээ дээр эхэлж турших нь хамгийн аюулгүй.
3. Бүх 4 Secret File болон Environment Variables-ийг шалгасны дараа deploy хийнэ.
4. `/` нүүр хуудас, `/admin`, `/bagsh/`, `/bagsh-admin` болон бүртгэл, AI боловсруулалт, Word таталт, төлбөрийн урсгалыг тус тус туршина.
5. Бүх туршилт амжилттай болсны дараа үндсэн домэйн/үйлчилгээнд шилжүүлнэ.

## Хязгаарлалт
Кодын JavaScript syntax шалгалт болон HTML давхардсан ID шалгалт амжилттай. Гэвч энэ орчноос Render, Supabase, Gemini, QPay-ийн нууц түлхүүрүүдэд нэвтэрч бодит production туршилт хийх боломжгүй. Иймээс “алдаагүй ажиллана” гэж баталж болохгүй; дээрх тохиргоо болон бодит тест зайлшгүй шаардлагатай.
